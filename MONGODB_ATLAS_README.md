## ⚡ Quick Start (5 Minutes)

### Step 1: Create MongoDB Account
1. Go to: https://www.mongodb.com/cloud/atlas
2. Click "Start Free"
3. Sign up with GitHub or email
4. Verify email

### Step 2: Create Cluster
1. Click "Build your own"
2. Select: AWS, ap-south-1 (or nearest), M0 Free
3. Click "Create Deployment"
4. Wait 5 minutes

### Step 3: Get Connection String
1. Click "Connect"
2. Select "Connect your application"
3. Choose Node.js
4. Copy the string
5. Replace `password` with your actual password

### Step 4: Update .env
```
File: D:\final-year-project\ai-hiring-system\.env

Replace:
MONGODB_URI=mongodb://localhost:27017/ai-hiring

With:
MONGODB_URI=mongodb+srv://aiHiringAdmin:PASSWORD@cluster0.xxxxx.mongodb.net/ai-hiring?retryWrites=true&w=majority
```

### Step 5: Restart Backend
```powershell
Ctrl + C (stop current)
node backend/server.js
```

### ✅ Done!
You should see: `✅ MongoDB connected`
