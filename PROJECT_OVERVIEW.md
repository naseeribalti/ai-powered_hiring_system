## 🚨 Common Issues & Quick Fixes

### **"Cannot connect to backend"**

- Check backend running: `npm start` in backend folder
- Check port 3000: `http://localhost:3000/api/health`
- Check MongoDB running: `mongosh` in terminal

### **"CORS Error"**

- Backend CORS is configured, should work
- Verify backend not crashed
- Restart both frontend and backend

### **"401 Unauthorized"**

- Token not saving? Check localStorage in DevTools
- Token expired? Login again
- Wrong token format? Check Postman Authorization header

### **"Cannot find component"**

- Check file path in import statement
- Ensure component file exists
- Use relative paths correctly (`./` for same folder)

### **"API returns 500 error"**

- Check backend logs for error
- Verify request body format in Postman first
- Run test from Postman collection

### **"Tests failing"**

- Start backend first (`npm start`)
- Clear test cache: `npm test -- --clearCache`
- Check database is running
- Review test output for specifics
